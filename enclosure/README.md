# sketchingpad cases

There are two versions of the sketchingpad case currently:

- skechingpad_case_soldered -- When the XIAO is soldered directly to the PCB

- sketchingpad_case_header -- If the XIAO board is connected via 5mm short female headers and short header pins


Note the "header" version allows for only 13mm of clearance. 
This is a very compact stack.
