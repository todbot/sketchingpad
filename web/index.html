sketchingpad flasher

Plug the sketchingpad's XIAO in over USB, pick a sketch, click Flash.
Chrome, Firefox, or Edge on desktop. Source and docs on GitHub.

This browser has no Web Serial, so it cannot flash. Use Chrome, Firefox, or Edge on a desktop, or the adafruit-nrfutil steps linked below.
Older, sensor-specific sketches
The first flash asks for the serial port twice: once for the running sketch, once for the bootloader it resets into. After that it goes straight through. If a flash stalls, double-tap the XIAO's reset button and flash again. Prefer the command line? See adafruit-nrfutil.
